## 这版修了什么（v1.1.1）

面板三连修，全是真机复现后追到根因的：

1. **打开 WebUI 白屏 1 秒+（根因级）**——首帧前连发 8 条桥命令把 JS 线程卡死，WebView 画不出来。改成"先画页面、再拉数据"：冷开首帧 5.7~6.3s 纯灰 → **约 1.1s 出内容**（A/B 同条件实测）。打开时仍有约 1 秒灰色过渡，那是 **KSU 容器窗口初始化**，所有模块的 WebUI 都有，模块侧改不了，如实说明。
2. **防线页切换日期没反应**——模板里 ref 被自动解包导致赋值静默失败（菜单关了、日期不动），逻辑移入 script 层，真机验证选 10-03 后拦截数/规则/事件流全部同步切换。
3. **日期菜单选项被裁掉一半**——滚动容器截断下拉底部，10-03 及以后根本点不到；改向上弹出，全部日期可达。
4. 顺手：立即释放/刷新 加底部 toast 反馈（原来提示写在页面顶部，蹲底部点按钮看不见）、底部导航改文档流根治防线页下沉、6 列统计改 3 列不折行、应用名不再被挤成竖排。

## 已知限制（诚实清单）

- 引擎只管 **cch\* 缓存态**进程；服务/前台/最近任务态由系统托管（设计如此）
- **双层防线的诚实边界**：adj=200 保活覆盖 lmkd 内存压力杀；AMS cached/empty 回收（按 procState 杀、不看 adj）由阶段二 COSGuard hook `killLocked` 按 reason 拦截（3 天 BLOCK 11 全正向）——但仅 **guard 模式**拦截、观察模式只记录，桥缺失时 fail-open 只记不拦，进程自身 exit/厂商私有杀点不承诺覆盖
- 对照组事实：微信昨夜同样死 15 次——系统对所有 App 一视同仁，无「微信免疫」；体感差异来自使用频率
- **KILL 动作必须带 :进程后缀**（整包封杀用 FREEZE）；出厂 KILL 名单为空，老 A1(2023) 名单 2026 年已全部失效，逐条自测
- hook lmkd 路线已论证排除（与 adj 同路径，挡不住 AMS/Hans，还引入黑盒二进制）
- 轻负载下模块安静无感（设计目标），效果仅重负载/多任务可感知
- Magisk 与 ColorOS 15 理论兼容、未经实机验证

## 安装

KSU 管理器 → 模块 → 本地安装 zip → 重启。防线功能需启用 zip 内 COSGuard（LSPosed，作用域：系统框架）→ 重启后 LSPosed 日志见 `COSGuard loaded, killLocked hooks=3`。

面板入口：模块页 → COSMemory → 打开（约 1 秒灰色为 KSU 容器初始化，随后骨架屏首帧，「连接中…」后数据到位）。
